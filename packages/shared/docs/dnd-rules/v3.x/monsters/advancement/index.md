# Monster Advancement

This section covers methods for creating extraordinary or unique monsters using a typical creature as the foundation.

## Advancement Methods

There are three primary methods for improving monsters:

- **[Adding Character Classes](class-levels.md)** — For intelligent, humanoid-shaped creatures
- **[Increasing Hit Dice](hit-dice.md)** — For non-humanoid or unintelligent creatures  
- **[Adding Templates](templates.md)** — For creatures with unusual heritage or changes

These methods are **not mutually exclusive** — a monster can use multiple advancement methods simultaneously.

## Quick Reference

### When to Use Each Method

| **Method** | **Best For** | **CR Calculation** |
|------------|--------------|-------------------|
| **Class Levels** | Intelligent humanoids | Associated: +1 per level<br>Nonassociated: +½ per level |
| **Hit Dice** | Non-humanoids, unintelligent | Varies by creature type |
| **Templates** | Special origins/changes | Template modifier |

### Ability Score Arrays

| **Array Type** | **Scores** | **Best For** |
|----------------|------------|--------------|
| **Standard** | 11, 11, 11, 10, 10, 10 | Most creatures |
| **Elite** | 15, 14, 13, 12, 10, 8 | PC classes |
| **Nonelite** | 13, 12, 11, 10, 9, 8 | NPC classes |
