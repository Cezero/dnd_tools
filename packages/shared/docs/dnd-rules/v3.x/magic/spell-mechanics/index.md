## Quick Reference

### Spell Format Elements

| **Element** | **Description** | **Example** |
|-------------|-----------------|-------------|
| **Name** | Common spell designation | *Fireball* |
| **School** | Magic category | Evocation [Fire] |
| **Level** | Class/level requirements | Sor/Wiz 3 |
| **Components** | Casting requirements | V, S, M |
| **Range** | Maximum distance | Long (400 ft + 40 ft/level) |
| **Duration** | Effect length | Instantaneous |

### Component Types
- **V (Verbal)** — Spoken magical words
- **S (Somatic)** — Hand gestures  
- **M (Material)** — Consumed components
- **F (Focus)** — Reusable magical tools
- **DF (Divine Focus)** — Holy symbols
- **XP** — Experience point costs

### Range Categories
- **Personal** — Caster only
- **Touch** — Must physically touch
- **Close** — 25 ft + 5 ft/2 levels  
- **Medium** — 100 ft + 10 ft/level
- **Long** — 400 ft + 40 ft/level
- **Unlimited** — No distance limit

### Duration Types
- **Instantaneous** — Immediate and permanent
- **Concentration** — While focusing
- **Rounds/minutes/hours** — Specific time
- **Permanent** — Until dispelled
- **Dismissible** — Caster can end

### Saving Throws
- **Fortitude** — Physical resistance
- **Reflex** — Dodging and evasion
- **Will** — Mental resistance
- **None** — No save allowed

### Save Results
- **Negates** — Prevents all effects
- **Half** — Reduces damage by 50%
- **Partial** — Reduces some effects
- **Special** — Unique mechanics
