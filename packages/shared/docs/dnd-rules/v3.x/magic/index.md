## Metamagic Feats

### Common Metamagic Effects
- **Empower Spell** — +50% numeric effects
- **Enlarge Spell** — Double range
- **Extend Spell** — Double duration  
- **Heighten Spell** — Increase effective level
- **Maximize Spell** — Maximum numeric effects
- **Quicken Spell** — Cast as swift action
- **Silent Spell** — No verbal component
- **Still Spell** — No somatic component
- **Widen Spell** — Double area of effect
