## Quick Reference

### Modifier Types and Stacking

| **Modifier Type** | **Stacks?** | **Common Sources** |
|-------------------|-------------|-------------------|
| **Ability** | Always | Ability scores |
| **Alchemical** | No | Alchemical items |
| **Armor** | No | Armor, spells |
| **Circumstance** | Yes | Situations, tools |
| **Competence** | No | Spells, magic items |
| **Deflection** | No | Spells, magic items |
| **Dodge** | Yes | Class features, spells |
| **Enhancement** | No | Magic weapons/armor |
| **Insight** | No | Divination effects |
| **Luck** | No | Divine effects |
| **Morale** | No | Emotions, leadership |
| **Natural Armor** | No | Creature hide, spells |
| **Profane** | No | Evil sources |
| **Racial** | No | Race traits |
| **Resistance** | No | Save bonuses |
| **Sacred** | No | Good sources |
| **Shield** | No | Shields, spells |
| **Size** | Always | Creature size |

### Stacking Examples

#### Attack Roll Modifiers
- **Base Attack Bonus**: +6
- **Strength modifier**: +3 (ability)
- **Enhancement bonus**: +2 (magic weapon)
- **Morale bonus**: +1 (bless spell)
- **Size modifier**: +1 (small size)
- **Total**: +13

#### Armor Class Modifiers
- **Base AC**: 10
- **Armor bonus**: +6 (full plate)
- **Shield bonus**: +2 (heavy shield)
- **Dexterity modifier**: +1
- **Natural armor**: +2 (amulet)
- **Deflection bonus**: +1 (ring of protection)
- **Total AC**: 22
