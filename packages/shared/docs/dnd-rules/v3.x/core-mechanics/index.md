# Core Mechanics

This section covers fundamental game mechanics that apply across all aspects of D&D 3.x.

## Core Mechanics Documentation

- **[Multiclass Characters](multiclass-characters.md)** — Rules for characters with levels in multiple classes

## Quick Reference

### Basic Mechanics

| **Mechanic** | **Formula** | **When Used** |
|--------------|-------------|---------------|
| **D20 Roll** | 1d20 + modifiers vs DC | Most checks |
| **Opposed Check** | 1d20 + mods vs 1d20 + mods | Direct competition |
| **Ability Check** | 1d20 + ability modifier | Basic ability use |
| **Skill Check** | 1d20 + skill ranks + ability mod | Skill attempts |

### Core Resolution System

| **Check Type** | **Success** | **Failure** |
|----------------|-------------|-------------|
| **DC 5** | Very Easy | Automatic unless 1 |
| **DC 10** | Easy | 50% for average character |
| **DC 15** | Moderate | Trained character needed |
| **DC 20** | Hard | Expert level required |
| **DC 25** | Very Hard | Master level required |
| **DC 30** | Nearly Impossible | Legendary achievement |

### Multiclass Rules Summary

| **Aspect** | **Calculation** |
|------------|-----------------|
| **Character Level** | Sum of all class levels |
| **Hit Points** | Sum from each class |
| **Base Attack Bonus** | Sum from each class |
| **Saving Throws** | Sum from each class |
| **Skill Points** | Based on each class gained |
| **Class Features** | All features from all classes |

|----------|-----------|-----------|-------------------|

| **Diminutive** | 1 ft | 0 ft | +4 |
| **Tiny** | 2½ ft | 0 ft | +2 |
| **Small** | 5 ft | 5 ft | +1 |
| **Medium** | 5 ft | 5 ft | +0 |
| **Large** | 10 ft | 10 ft | -1 |

### Common Modifiers

| **Source** | **Type** | **Stacks?** |
|------------|----------|-------------|
| **Ability scores** | Inherent | Always |
| **Enhancement** | Enhancement | No (highest only) |
| **Circumstance** | Circumstance | Yes |
| **Dodge** | Dodge | Yes |
| **Luck** | Luck | No (highest only) |
| **Morale** | Morale | No (highest only) |

### Dice Conventions

| **Die Type** | **Average** | **Common Uses** |
|--------------|-------------|----------------|
| **d4** | 2.5 | Small weapons, some spells |
| **d6** | 3.5 | Standard weapons, many spells |
| **d8** | 4.5 | Martial weapons, hit dice |
| **d10** | 5.5 | Heavy weapons, percentile |
| **d12** | 6.5 | Great weapons, barbarian HD |
| **d20** | 10.5 | All checks and saves |
