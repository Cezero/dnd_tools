## Quick Reference

### Skill Check Formula

```
Skill Check = 1d20 + Skill Rank + Ability Modifier + Misc Modifiers
```

### Skill Points by Class

| **Class** | **Skill Points** | **Key Skills** |
|-----------|------------------|----------------|
| **Barbarian** | 4 + Int modifier | Climb, Jump, Listen, Survival |
| **Bard** | 6 + Int modifier | All social skills, Knowledge |
| **Cleric** | 2 + Int modifier | Concentration, Heal, Knowledge (religion) |
| **Druid** | 4 + Int modifier | Animal Empathy, Knowledge (nature), Survival |
| **Fighter** | 2 + Int modifier | Climb, Jump, Ride, Swim |
| **Monk** | 4 + Int modifier | Balance, Climb, Jump, Listen |
| **Paladin** | 2 + Int modifier | Diplomacy, Heal, Ride |
| **Ranger** | 6 + Int modifier | Hide, Move Silently, Survival, Track |
| **Rogue** | 8 + Int modifier | All Dex and Int skills, social skills |
| **Sorcerer** | 2 + Int modifier | Concentration, Knowledge (arcana) |
| **Wizard** | 2 + Int modifier | Concentration, Knowledge skills |

### Skill Costs

| **Skill Type** | **Cost per Rank** | **Maximum Ranks** |
|----------------|-------------------|-------------------|
| **Class skill** | 1 skill point | Character level + 3 |
| **Cross-class skill** | 2 skill points | (Character level + 3) ÷ 2 |

### Opposed Checks

| **Active Skill** | **Opposed By** | **Situation** |
|------------------|----------------|---------------|
| **Bluff** | Sense Motive | Deception vs detection |
| **Disguise** | Spot | Concealment vs recognition |
| **Hide** | Spot | Concealment vs detection |
| **Move Silently** | Listen | Stealth vs detection |
| **Sleight of Hand** | Spot | Misdirection vs observation |

### Synergy Bonuses

Characters with **5+ ranks** in certain skills gain **+2 synergy bonuses**:

| **Skill with 5+ Ranks** | **Provides +2 Bonus To** |
|-------------------------|---------------------------|
| **Bluff** | Diplomacy, Disguise, Sleight of Hand |
| **Knowledge (arcana)** | Spellcraft |
| **Search** | Survival (tracking) |
| **Tumble** | Balance, Jump |
| **Use Rope** | Climb, Escape Artist |
