# D&D 3.x Skills Summary

## Skill Points and Ranks

### Class Skills vs Cross-Class Skills

**Class Skills:**
- Skills found on your character's class skill list
- **Cost**: 1 skill point = 1 rank
- **Maximum Rank**: Character level + 3

**Cross-Class Skills:**
- Skills NOT found on your character's class skill list  
- **Cost**: 1 skill point = ½ rank
- **Maximum Rank**: (Character level + 3) ÷ 2 (do not round)

> **Important**: Half ranks do not improve your skill check, but two ½ ranks make 1 rank.

### Maximum Rank Rules

- **Class Skill Maximum**: Character level + 3
- **Cross-Class Maximum**: Half of class skill maximum (no rounding)
- **Multiclass Rule**: If a skill is a class skill for ANY of your classes, use the class skill maximum regardless of which class you're buying it with

### Skill Point Spending

- You **cannot save** skill points to spend later
- All skill points must be spent when gained

## Using Skills

### Basic Skill Check Formula

```
Skill Check = 1d20 + Skill Modifier
```

**Where Skill Modifier =**
- Skill ranks
- \+ Ability modifier (key ability for that skill)
- \+ Miscellaneous modifiers

### Success Conditions

The roll works like attack rolls or saving throws—higher is better. You either need to:
- **Match or exceed** a Difficulty Class (DC), OR
- **Beat** another character's opposed check result

## Skill Modifier Components

### 1. Skill Ranks
- Based on skill points invested in the skill
- Many skills can be used **untrained** (with 0 ranks)

### 2. Ability Modifier  
- Uses the skill's **key ability** modifier
- Key ability is specified in each skill's description

### 3. Miscellaneous Modifiers
Examples include:
- **Racial bonuses** - Innate species advantages
- **Armor check penalties** - Bulky armor hindering dexterity
- **Feat bonuses** - Training and specialization benefits
- **Circumstance modifiers** - Situational advantages/disadvantages
- **Equipment bonuses** - Tools and gear improvements
