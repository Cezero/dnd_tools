# Navigation in the Wilderness

Navigation through wilderness areas requires careful planning and skill to avoid becoming lost.

## Navigation Fundamentals

### [Getting Lost](getting-lost.md)
Complete guide to wilderness navigation mechanics, including:
- **Conditions that cause getting lost** — Poor visibility, difficult terrain
- **Survival check requirements** — DCs for different terrain types  
- **Effects of being lost** — Random movement and recognition
- **Regaining bearings** — Methods to get back on course

## Quick Reference

### Navigation DCs

| **Circumstance** | **Survival DC** |
|------------------|-----------------|
| Moor/hill with map | 6 |
| Mountain with map | 8 |
| Moor/hill no map | 10 |
| Poor visibility | 12 |
| Mountain no map | 12 |
| Forest | 15 |

### Safe Travel Routes
- Following **roads, trails, or streams** prevents getting lost
- **Obvious landmarks** provide navigation reference points  
- **Celestial navigation** when sky is visible

### Navigation Bonuses
- **+2 bonus** for 5+ ranks in Knowledge (geography/local)
- **+4 bonus** when conditions improve (fog lifts, sun rises)
