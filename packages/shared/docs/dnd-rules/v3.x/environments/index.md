## Quick Reference

### Environment Types

| **Environment** | **Primary Challenges** | **Common Features** |
|-----------------|------------------------|---------------------|
| **Arctic** | Extreme cold, difficult terrain | Ice, snow, limited visibility |
| **Desert** | Heat, dehydration, sandstorms | Sand dunes, mirages, oases |
| **Forest** | Dense vegetation, limited visibility | Trees, undergrowth, wildlife |
| **Hills** | Uneven terrain, slopes | Rolling terrain, scattered trees |
| **Marsh** | Shallow water, disease | Standing water, thick vegetation |
| **Mountains** | Altitude, cold, avalanches | Rocky terrain, steep slopes |
| **Plains** | Open terrain, weather exposure | Grasslands, few landmarks |
| **Underground** | Darkness, confined spaces | Tunnels, chambers, artificial structures |

### Weather Effects

| **Weather** | **Visibility** | **Movement** | **Ranged Attacks** | **Special Effects** |
|-------------|----------------|--------------|-------------------|---------------------|
| **Clear** | Normal | Normal | Normal | None |
| **Overcast** | Normal | Normal | Normal | None |
| **Light Rain** | ×¾ | Normal | -2 | Perception -2 |
| **Heavy Rain** | ×½ | ×¾ | -4 | Perception -4 |
| **Light Snow** | ×¾ | ×¾ | -2 | Perception -2 |
| **Heavy Snow** | ×¼ | ×½ | Impossible | Perception -8 |
| **Fog** | ×¼ | ×¾ | Varies | Concealment |

### Temperature Effects

| **Temperature** | **Range** | **Effects** |
|-----------------|-----------|-------------|
| **Extreme Cold** | Below -20°F | 1d6 cold damage/10 min (Fort DC 15) |
| **Severe Cold** | -21°F to 0°F | 1d4 cold damage/hour (Fort DC 15) |
| **Cold** | 1°F to 40°F | Fort save vs fatigue |
| **Moderate** | 41°F to 85°F | None |
| **Hot** | 86°F to 110°F | Fort save vs fatigue |
| **Severe Heat** | 111°F to 140°F | 1d4 fire damage/hour (Fort DC 15) |
| **Extreme Heat** | Above 140°F | 1d6 fire damage/10 min (Fort DC 15) |
