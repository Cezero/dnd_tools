# Combat Modifiers

This section covers situational modifiers that affect combat.

## Modifiers and Conditions

- **[Combat Modifiers](combat-modifiers.md)** — Attack roll and AC modifiers, cover, concealment, flanking

## Quick Reference

### Attack Roll Modifiers

| **Situation** | **Modifier** |
|---------------|--------------|
| **Attacker flanking defender** | +2 |
| **Attacker on higher ground** | +1 |
| **Attacker prone** | -4 |
| **Attacker dazzled** | -1 |
| **Defender invisible** | -2 (50% miss chance) |
| **Defender behind cover** | -2 to -8 |
| **Defender concealed** | 20% miss chance |
| **Defender prone** | +4 (melee), -4 (ranged) |
| **Defender helpless** | +4¹ |
| **Defender stunned/cowering** | +2 |
| **Range penalty** | -2 per range increment |

> ¹ Melee attacks against helpless targets are automatic hits and can be coup de grace attempts.

### Armor Class Modifiers

| **Situation** | **AC Modifier** |
|---------------|-----------------|
| **Behind cover** | +2 to +8 |
| **Concealed** | Special (miss chance) |
| **Cowering** | -2 |
| **Entangled** | +0² |
| **Flat-footed** | Lose Dex bonus |
| **Grappling** | +0² |
| **Helpless** | -4² |
| **Kneeling/sitting** | -2 |
| **Pinned** | -4² |
| **Prone** | -4 against ranged, +4 against melee |
| **Stunned** | -2² |
| **Surprised** | Lose Dex bonus |

> ² Also lose Dex bonus to AC (if any).

### Cover

| **Cover Type** | **AC Bonus** | **Reflex Save Bonus** |
|----------------|--------------|----------------------|
| **¼ cover** | +2 | +1 |
| **½ cover** | +4 | +2 |
| **¾ cover** | +7 | +3 |
| **9/10 cover** | +10 | +4 |

### Concealment

| **Concealment** | **Miss Chance** |
|-----------------|----------------|
| **Partial** (20%) | 20% |
| **Total** (50%) | 50% |

### Flanking

Two characters **flank** when they are on **opposite sides** of a target and both **threaten** the target. Flanking provides a **+2 bonus** on attack rolls.
