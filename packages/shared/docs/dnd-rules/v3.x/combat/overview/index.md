## Quick Reference

### Combat Sequence

1. **Determine initiative** (1d20 + Dex modifier + other modifiers)
2. **Surprise round** (if any) — surprised creatures can't act
3. **Initiative order** — highest to lowest
4. **Repeat each round** — same initiative order

### Key Combat Statistics

#### Attack Roll
```
Attack Roll = 1d20 + Base Attack Bonus + Ability Modifier + Size Modifier + Misc Modifiers
```

#### Armor Class
```
AC = 10 + Armor Bonus + Shield Bonus + Dex Modifier + Size Modifier + Natural Armor + Misc Modifiers
```

#### Damage Roll
```
Damage = Weapon Damage + Ability Modifier + Misc Modifiers
```

#### Saving Throws
```
Save = 1d20 + Base Save Bonus + Ability Modifier + Misc Modifiers
```

### Size Modifiers

| **Size** | **AC/Attack Modifier** |
|----------|------------------------|
| Fine | +8 |
| Diminutive | +4 |
| Tiny | +2 |
| Small | +1 |
| Medium | +0 |

| Huge | -2 |
| Gargantuan | -4 |

### Flat-Footed Condition

A character is **flat-footed** when:
- They haven't acted in combat yet
- They are surprised
- They lose their Dex bonus to AC

**Effects**:
- Lose Dex bonus to AC
- Can't make attacks of opportunity
- Rogues can sneak attack
