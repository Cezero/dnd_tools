## 🚀 **Quick Reference Tables**

### Combat Sequence
1. **Roll Initiative** (1d20 + Dex + modifiers)
2. **Surprise Round** (if applicable)
3. **Combat Rounds** (highest initiative to lowest)
4. **Repeat** until combat ends

### Action Economy (Normal Round)
- **1 Standard Action** OR **1 Full-Round Action**
- **1 Move Action** (can trade standard for extra move)
- **Any number of Free Actions** (within reason)
- **1 Swift Action** per turn
- **1 Immediate Action** per round (counts as next turn's swift)
- **1 Five-Foot Step** (if no other movement)

### Core Formulas

#### Attack Roll
```
1d20 + BAB + Ability Mod + Size Mod + Misc
```

#### Armor Class  
```
10 + Armor + Shield + Dex + Size + Natural + Misc
```

#### Damage Roll
```
Weapon Damage + Ability Mod + Misc
```

#### Saving Throw
```
1d20 + Base Save + Ability Mod + Misc
```
