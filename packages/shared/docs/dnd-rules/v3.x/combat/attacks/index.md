## Quick Reference

### Special Attack Summary

| **Attack Type** | **Prerequisites** | **Success Effect** |
|-----------------|------------------|--------------------|
| **Aid Another** | Adjacent to enemy & friend | +2 bonus to friend |
| **Bull Rush** | Same size or smaller target | Push back 5+ feet |
| **Charge** | 10+ ft straight line | +2 attack, -2 AC |
| **Disarm** | Melee weapon | Remove opponent's weapon |
| **Feint** | Bluff vs Sense Motive | Remove Dex bonus to AC |
| **Grapple** | Successful touch attack | Control opponent |
| **Overrun** | Same size or smaller target | Knock prone, move through |
| **Sunder** | Melee weapon | Damage equipment |
| **Trip** | Same size or smaller target | Knock prone |
