## Quick Reference

### Action Economy Summary

| **Round Type** | **Available Actions** |
|----------------|----------------------|
| **Normal Round** | 1 Standard + 1 Move + Free Actions + 1 Swift |
| **Restricted Round** | 1 Standard OR 1 Move + Free Actions |
| **Full-Round Action** | 1 Full-Round + 5-foot step + Free Actions |

### Common Action Timing

| **Action** | **Type** | **AoO?** |
|------------|----------|----------|
| **Attack (melee)** | Standard | No |
| **Attack (ranged)** | Standard | Yes |
| **Cast spell** | Standard | Yes |
| **Full attack** | Full-round | No |
| **Move** | Move | Yes (leaving) |
| **5-foot step** | No action | No |
| **Total defense** | Standard | No |
