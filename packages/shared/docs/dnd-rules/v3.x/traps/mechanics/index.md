## Quick Reference

### Detection DCs

| **Trap Type** | **Search DC** | **Disable DC** | **Requirements** |
|---------------|---------------|----------------|------------------|
| **Simple Mechanical** | 20 | 20 | None |
| **Complex Mechanical** | 21+ | 21+ | Trapfinding |
| **Magic Trap** | 25 + spell level | 25 + spell level | Trapfinding |

### Common Trigger Types

| **Trigger** | **Activation** | **Best For** |
|-------------|----------------|--------------|
| **Location** | Enter 5-ft square | Hallways, doors |
| **Proximity** | Approach within range | Large areas |
| **Touch** | Physical contact | Specific objects |
| **Visual** | Line of sight | Guard areas |
| **Sound** | Noise detection | Quiet areas |
| **Timed** | Set intervals | Automatic cycles |

### Reset Types

| **Reset Type** | **Recovery Time** | **Requirements** |
|----------------|-------------------|------------------|
| **No Reset** | Permanent | Rebuild trap |
| **Manual** | ~1 minute | Physical access |
| **Repair** | Varies | Materials + skill |
| **Automatic** | Immediate/delayed | Built-in mechanism |
