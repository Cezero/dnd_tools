## Quick Reference

### Trap Types

| **Type** | **Detection** | **Disarm** | **Examples** |
|----------|---------------|------------|--------------|
| **Mechanical** | Search DC | Disable Device DC | Pit traps, crossbow traps |
| **Magical** | Search DC | Dispel Magic | Glyph of warding, symbol spells |
| **Spell** | Varies | Dispel Magic | Triggered spell effects |

### Trap Elements

| **Element** | **Purpose** | **Examples** |
|-------------|-------------|--------------|
| **Trigger** | Activates trap | Pressure plate, tripwire, proximity |
| **Detection** | Finds trap | Visual, magical aura |
| **Attack** | Harm target | Dart, falling block, spell |
| **Reset** | Rearms trap | Manual, automatic, no reset |

### Avoiding Traps

| **Method** | **Requirements** | **Success** |
|------------|------------------|-------------|
| **Find and disable** | Search + Disable Device | Trap neutralized |
| **Trigger safely** | Remote activation | Know trap location |
| **Bypass** | Alternative route | Avoid trigger area |
| **Absorb damage** | High AC/HP | Take reduced damage |

### Trap Reset Mechanisms

|----------------|----------|------------------|
| **Manual** | 1 minute | Someone resets |
| **Repair** | 1 day | Craft check |
| **Automatic** | 1 round | Built-in mechanism |
| **No reset** | — | Single use only |
