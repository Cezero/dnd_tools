# Spell-Like Abilities

This section covers **spell-like abilities** and related magical mechanics for creatures.

## Spell-Like Ability Documentation

### Core Mechanics
- **[Spell Resistance](spell-resistance.md)** — Detailed mechanics for resisting spells and spell-like abilities
- **[Creature Spellcasting](creature-spellcasting.md)** — Rules for creatures that cast spells like class members

## Key Properties of Spell-Like Abilities

**Spell-like abilities** work just like the spell of that name, with the following characteristics:

### Activation
- **No components**: No verbal, somatic, or material component required
- **No focus or XP cost**: These are not required
- **Mental activation**: The user activates it mentally
- **Armor doesn't interfere**: Even if the ability resembles an arcane spell with a somatic component

### Timing and Actions
- Takes the **same amount of time** as the spell it mimics (usually 1 standard action)
- **Provokes attacks of opportunity** when used while threatened
- Can make a **Concentration check** to use defensively and avoid provoking
- **Can be disrupted** just as a spell can be

### Magical Properties
- **Subject to spell resistance**
- **Subject to being dispelled** by *dispel magic*
- **Do not function** in areas where magic is suppressed or negated
- **Cannot be used to counterspell**, nor can they be counterspelled

### Usage Limits
- Usually has a **limit on how often** it can be used
- A spell-like ability that can be used **"at will"** has no use limit

### Caster Level
- For creatures with spell-like abilities, a **designated caster level** defines:
  - How difficult it is to **dispel** their spell-like effects
  - Any **level-dependent variables** (such as range and duration) the abilities might have
- The creature's caster level **never affects which spell-like abilities** the creature has
- Sometimes the given caster level is **lower than the level** a spellcasting character would need to cast the spell of the same name
- If **no caster level is specified**, the caster level is **equal to the creature's Hit Dice**

### Saving Throws
The saving throw (if any) against a spell-like ability is:

**10 + the level of the spell the ability resembles or duplicates + the creature's Cha modifier**

### Class Variants
- Some spell-like abilities duplicate spells that **work differently** when cast by characters of different classes
- A monster's spell-like abilities are presumed to be the **sorcerer/wizard versions**
- If the spell in question is not a sorcerer/wizard spell, then default to **cleric, druid, bard, paladin, and ranger**, in that order

### Mixed Abilities
- Some creatures are actually **sorcerers of a sort**
- They cast arcane spells as sorcerers do, **using components when required**
- An individual creature could have **some spell-like abilities** and also **cast other spells as a sorcerer**
